GitHubSource
in package
  • Application
implements Source

FinalYes
GitHubSource.php : 36

The owner's GitHub activity: the user events feed (pushes, pull requests, issues, reviews, comments, releases, …) plus a commit search, which still carries commit messages when a push event's payload does not.

Private-repository activity is dropped unless $includePrivate is set, so a token with private scope cannot leak private repo names into a public post.
