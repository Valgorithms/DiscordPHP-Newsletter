JsonClient
in package
  • Application

FinalYes
JsonClient.php : 31

Tiny async JSON client for the third-party APIs the newsletter reads (GitHub, Steam) and writes (GitHub contents, for the websites), driven by the bot's ReactPHP loop.

The transport is injectable, exactly like OllamaClient, so the sources can be unit-tested with canned responses and no network.
