Writer
in package

FinalYes
Writer.php : 43

Everything the local model writes, as a short chain of small prompts (small local models do far better on several focused asks than one big one):

  1. notes() — per source, turn raw activity into plain-English notes;
  2. compose() — write the newsletter from all notes, as Markdown prose;
  3. review() — fact-check the draft against the notes and fix it;
  4. revise() — apply the owner's requested edits, later, on demand.

Replies are plain Markdown (Draft::fromMarkdown()), not JSON: local models write prose far more reliably than they fill in a schema, and some "thinking" models return nothing at all when forced into one.

Calls run one after another, never in parallel, so a single local GPU is not asked to juggle several generations at once.
