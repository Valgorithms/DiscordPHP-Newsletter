SitePublisher
in package
  • Application

FinalYes
SitePublisher.php : 36

Publishes approved editions to static websites by committing them to a JSON file in each site's repository (GitHub contents API). The push to the site's branch then rebuilds and deploys it, as any other change would.

Every target file has the same shape, {"editions": [ … newest first … ]}, and an edition is replaced in place when it is published again.
