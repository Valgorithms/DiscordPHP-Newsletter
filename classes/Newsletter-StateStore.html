StateStore
in package
  • Application

FinalYes
StateStore.php : 26

Tiny JSON-backed store (`var/state.json`) for everything that must survive a restart: editions and their approval state, the end of the last covered window, and Steam playtime snapshots.

Writes are atomic (temp file + rename), so a crash mid-save never leaves a truncated file behind.
