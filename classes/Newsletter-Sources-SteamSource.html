SteamSource
in package
  • Application
implements Source

FinalYes
SteamSource.php : 36

The owner's Steam activity: playtime per game inside the window (the difference between two lifetime-playtime snapshots) and achievements whose unlock time falls inside it.

The profile's game details must be public, or the key must belong to the account, for the Web API to return playtime.
