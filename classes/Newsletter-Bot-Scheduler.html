Scheduler
in package
  • Application

FinalYes
Scheduler.php : 32

Fires the daily edition at the configured local time, on the bot's event loop (no cron needed), and catches up once on startup when the bot was down at the scheduled time.

Each scheduled window starts where the previous one ended, so nothing falls between two editions even if a run is late.
