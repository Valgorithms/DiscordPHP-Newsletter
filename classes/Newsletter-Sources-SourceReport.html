in package

FinalYes
SourceReport.php : 26

What one source found inside a {@see \Newsletter\Window}: plain-language highlight lines (the facts the LLM may use), a few headline numbers, and any errors that made the picture incomplete.

Everything is plain data so an edition can be persisted with the facts it was written from, and revised later against the same facts.
